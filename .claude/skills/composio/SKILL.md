\# Composio - SaaS Integration Layer



Connect Claude Code to external services and automate workflows.



\## Popular Integrations

\- \*\*Slack\*\* - Send messages, create channels, post notifications

\- \*\*Google Workspace\*\* - Auto-generate Sheets, Docs, Drive files

\- \*\*GitHub\*\* - Create issues, PRs, commits, manage repos

\- \*\*Jira\*\* - Create tickets, update workflows

\- \*\*Salesforce\*\* - Sync CRM data, create contacts

\- \*\*Stripe\*\* - Process payments, manage customers

\- \*\*Mailchimp\*\* - Send campaigns, manage subscribers

\- \*\*Zapier\*\* - Connect to 2000+ apps



\## For 4bio Project Use Cases

1\. \*\*Slack Notifications\*\* - Alert when sales are completed/delivered

2\. \*\*Google Sheets Reports\*\* - Auto-export daily sales report

3\. \*\*GitHub Issues\*\* - Create bug tickets when QA finds issues

4\. \*\*Email Alerts\*\* - Notify on inventory low stock



\## When to Use

\- Integrating with external services

\- Automating notifications

\- Syncing data across platforms

\- Creating workflows with webhooks



\## Usage

Ask: `/composio "I need to \[integration task]"`



Example: "Send Slack notification when order status changes to 'delivered'"
