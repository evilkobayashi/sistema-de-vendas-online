\# Frontend Design System



When designing UI components, pages, or dashboards:



\## Core Principles

1\. \*\*Avoid AI defaults\*\* - No Inter font + purple gradient + minimal cards

2\. \*\*Bold aesthetic choices\*\* - Intentional color, typography, spacing

3\. \*\*Distinctive design\*\* - Look professionally designed, not AI-generated

4\. \*\*Purposeful animations\*\* - Only animate when it adds value



\## Design Process

1\. Understand the context (what's this for?)

2\. Choose a color palette (intentional, not random)

3\. Pick typography (clear hierarchy)

4\. Design components (cards, buttons, forms)

5\. Add micro-interactions (smooth, purposeful)



\## When to Use

\- Building new UI features

\- Redesigning existing components

\- Creating dashboards or interfaces

\- Before writing any HTML/CSS



\## Usage

Ask: `/frontend-design "describe what you want to design"`
